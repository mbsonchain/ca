# Visit Conamore

Map-based site for visitconamore.com. Static HTML, CSS and JavaScript; no dependencies or backend.

- `/`: supplied blank map on pure white, CONAMORE in Articulat Heavy CF at weight 900 with tight spacing, and Courier navigation. Both the map and title link to the guide. The shared header highlights home in pink; the map sits slightly lower, centered in the space between header and footer.
- `/travel-guide`: an enlarged map that stays within the screen on desktop and mobile. The 22 names from the supplied reference, with Sfiga corrected, plus the user-requested Island Formal marker in the central mountains. Mouse hover and keyboard focus reveal square previews. Mouse clicks open place pages; touch opens the preview first. Escape and the close control dismiss previews. Clicking or tapping white space toggles place names, including the white paper within the image; colored terrain and locations do not toggle them. The background is also a keyboard-accessible toggle. Names are separate text, with Orangepoint to the left and Freetown Formal to the right, constrained to remain on screen. Sant’Amore is offset 9px down and Orangepoint 9px up. No visible toggle or place index.
- `/travel-guide/<place>`: direct-linkable place pages with a map detail, geographic description and onward links.
- `/visit-conamore`: Matteo's supplied introduction in Courier beneath the solid CONAMORE wordmark, which links home. The final “here” link uses pink text and opens the full interview. The desktop introduction fits between the navigation bars with evenly distributed paragraph spacing, retaining the full interview's logo size and column width. Narrow or short desktop windows tighten the line spacing while keeping the copy at 14px. Mobile uses normal page scrolling. Very short windows retain accessible overflow rather than clipping the text. There is no nested reader or slider.
- `/visit-conamore/conamore-is-a-place`: the complete supplied interview in Courier with bold questions and preserved DF/MS labels. It begins with the first question beneath the CONAMORE logo, without a separate title. The original URL is retained for existing links. It includes all eleven exchanges and ends with “MS: Everything.” The closing DF thank-you was removed at Matteo's request. The page scrolls naturally, keeps Visit Conamore highlighted in the footer, and provides a return link to the introduction.
- `/mobile-preview`: 390 × 844 preview frame. Add `?page=visit-conamore`, `?page=visit-conamore/conamore-is-a-place`, or `?page=travel-guide` to select a page.
- `/desktop-preview`: interactive 1440 × 900 desktop preview scaled to fit the browser panel, with the same optional `page` query parameter.

Desktop flowers: four copies of Matteo's pink flower sit in the guide's side margins at widths of 900px and above, with varied sizes and spacing inspired by his flower pattern. Each flower links to Visit CONAMORE and is keyboard accessible. The surrounding white space still toggles map names; following a flower also works while a location card is open. The map's size and center are unchanged. The desktop Visit CONAMORE introduction has five pink flower sketches in matching straight columns centered in both side margins, with the left drawings mirrored horizontally; the full interview repeats the same five sketches down both margins for the entire article, at approximately 150px intervals. The column length and number of flowers adapt when the text reflows. Below 900px, all flowers are 26px wide, matching the previously displayed fourth flower. One sits beside the logo, with the others placed sparingly in existing breaks between paragraphs and questions, roughly 180px apart. On the mobile introduction, flowers 2, 5 and 6 sit 8px higher and flower 4 sits 4px higher, and a final centered flower below the text has extra clearance above the footer. Their positions follow the text as it reflows, including after the logo font loads, and they do not intercept taps or scrolling. The flowers use the same softened artwork as the guide. The text column is independent of the guide, up to 1000px wide on desktop and with 20px side margins on mobile. `assets/conamore-flower.png` is copied unchanged from the supplied `Desktop/desert formal/flower.png` (583 × 618, transparent PNG). A dedicated display filter lifts the dark outlines to soft charcoal, preserving the light pink/yellow colors and original transparency.

Home and travel guide use the same available map area and aspect ratio at every breakpoint, so navigation does not change the map's scale or center. The mobile homepage wordmark is centered vertically over that map area. Every entry to the guide starts with names hidden. Above 640px wide, Freetown's label sits 9px higher and Goldpoint's 9px lower; their dots and mobile label positions are unchanged.

Tapped location cards stay open after finger lift or focus changes until explicitly dismissed. Hover auto-close applies to mouse interactions. Clicking outside an open card dismisses it when the tap completes, without changing name visibility; a subsequent white-space click toggles names normally. The dismissal guard covers mouse, touch, pen and keyboard activation, while preserving card controls, marker selection and navigation. Regression checks exercise the actual card lifecycle, including unfocused touch buttons and delayed dismissal taps.

## Run

`npm run check` validates syntax. `npm test` checks white-space toggling, pixel coordinate mapping, label bounds and cleanup. `npm run build` creates `dist/`. `npm run dev` serves the built site at http://127.0.0.1:4175.

## Content and provenance

`places.js` holds the names, image coordinates, short descriptions and links. The first-pass descriptions are based on visible geography in the supplied reference, not new mythology. Hollywood retains its original caption. Place stories can replace these descriptions later.

`collection.js` contains the supplied `collectionIntroduction` paragraphs, `interviewPath`, and `interviewArticle`. The interview was transcribed from Matteo's attached “Pasted text.txt” on 15 October 2026, preserving the interview's words, speaker order, and answer paragraphs except for the requested removal of DF's closing thank-you and the correction from “touch someone” to “touch something.” MS’s sentence capitalization, proper names, and punctuation are lightly edited; DF’s wording is unchanged and CONAMORE is uppercase throughout. A word-by-word check against the attachment confirmed the remaining eleven exchanges were unchanged apart from case and punctuation. The introduction is the separately supplied editorial text, without the old launch-date copy. Blocks support paragraphs (`type: 'paragraph', text`), questions with answers (`type: 'qa', question, answer`), and credited quotations (`type: 'quote', text, credit`). All content is plain text. `article.js` escapes it and renders the interview as unhighlighted questions beneath the CONAMORE page heading. The desktop introduction keeps the full interview's logo size and fits the viewport with even paragraph gaps. The full interview and mobile introduction use document scrolling; history restores the document position. The interview has its own generated HTML entry so direct links and refreshes work.

Assets:
- `conamore-flower-sketch-1.svg` through `conamore-flower-sketch-5.svg`: original vector paths extracted from the supplied `Note Dec 25, 2025.pdf`, retaining the pink and yellow colors. The two page-one flowers, the colored flower and small lower-right flower on page two, and the page-three flower form the mirrored desktop columns. Crossed-out experiments are omitted.
- `conamore-map.png`: supplied `blank map 1.png`, copied without modification.
- `conamore-map-labelled.png`: supplied `map with text.png`, copied without modification.
- `conamore-collection-logo.png`: original standalone logo retained as an unused asset; the collection now uses the home wordmark.

The maps use a shared SVG display filter to lift the near-white paper texture to pure white without changing coordinates or resizing the source art. Dark and mid-tone channels remain unchanged. Both the blank and labelled versions use the same treatment. The original full-map archive page, captions and image are removed from the source and built output. Each build clears generated output before copying current assets, preventing stale pages or images from shipping.

All pages share home (left), formal (center, desertformal.com), and strikeout (right, strikeout.us) navigation. The current page is pink instead of underlined, including home in the homepage header. Mobile includes compact navigation, a bounded map layout and safe-area-aware footer spacing. Home, guide and the desktop collection introduction fit within the viewport; the interview, mobile introduction and place-detail pages use document scrolling. On the editorial pages, the navigation is sticky. The travel guide has desktop side flowers; the desktop introduction has matching columns of five original flower sketches in both margins, mirrored on the left. The interview repeats these mirrored desktop sketches through its full height. Both editorial pages use small flower accents beside the mobile logo and in text breaks. The CONAMORE wordmark retains Articulat Heavy; introduction and interview text and questions all use the same 14px Courier New/Courier size on desktop and mobile. Paragraphs, questions, exchanges, and the space below the logo have wider vertical spacing. CONAMORE is always uppercase in site copy, page titles, and navigation; URL slugs stay lowercase. The former `/travel-guide/sfsga` address redirects to `/travel-guide/sfiga`.

The existing Adobe Fonts kit is used for the homepage title. The kit registers the real 900 face under the separate `articulat-heavy-cf` family. Footer and small interface text use Courier New/Courier, matching the current website interface. No font binaries are redistributed.

## Release and verification

The user authorized the first production release on 14 October 2026, including the heavier CONAMORE title. Production deploys from `main` through the existing Vercel integration. No Shopify data, credentials, theme backups or private store exports are included.

Syntax validation and static output/link checks pass. Initial browser QA was blocked because the browser could not verify its admin-enforced security policy. Visual appearance and touch interaction still need a browser review.
